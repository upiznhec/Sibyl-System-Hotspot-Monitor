# Instructions for Claude Code

The instructions for any AI agent working on Sibyl are in [AGENTS.md](AGENTS.md). Read it in full and follow it.

The person may not be technical and has not read the guide. When you need something from them, ask at that moment, one thing at a time, as AGENTS.md describes under "Talking to the person": use the AskUserQuestion tool for choices and yes-or-no questions, and one short chat message for things they paste, such as a link. Never ask them to paste a key, token or webhook address into the chat. For a key they make, give them the `save-secret.js` command; in the Claude app, a one-line command in a `bash` code block gets a Run button. What you copy for them yourself, you save from the clipboard without showing it (AGENTS.md, "Keys and logins"). Never type their passwords.

For logins and account steps, follow "Keys and logins" too. One-time account steps happen in the person's own browser or app. With Claude's Chrome extension you can work in their signed-in Chrome, and with computer use in their apps; there you do the steps yourself, as "Who does what" describes: everything for Telegram, Slack and Discord, and the clicks before the key for YouTube and X. On Meta's sites the person does every click. For pages you read every day, the Claude app's browser pane keeps sign-ins between sessions; if its ⋮ menu offers to import a site's sign-in from the person's browser, suggest that for the one site.
