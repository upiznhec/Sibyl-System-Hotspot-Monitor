# Instructions for Claude Code

The instructions for any AI agent working on Sibyl are in [AGENTS.md](AGENTS.md). Read it in full and follow it.

The person may not be technical and has not read the guide. When you need something from them, ask at that moment, one thing at a time, as AGENTS.md describes under "Talking to the person": use the AskUserQuestion tool for choices and yes-or-no questions, and one short chat message for things they paste, such as a key or a link. Never type their passwords.
