# Sibyl 热点监控（Workflow Library 版）

本仓库 fork 自 Misaka Studio 的 [Sibyl System Hotspot Monitor](https://github.com/liray0919/Sibyl-System-Hotspot-Monitor) v1.3.20（MIT License），为非商业项目 Social Media AI Workflow Library 改成了英文版：

- 来源改为 Google Trends、TikTok Creative Center、Wikipedia，以及用户关注的 YouTube 频道和网站；
- 领域由用户和自己的 agent 一起设定；
- 保留原版的播报格式和推送方式，可推送到 Slack、Discord、企业微信或 Telegram；没有推送时存成文件，用户问 agent 时才展示。

使用说明为英文：[README.md](README.md)、[docs/guide.md](docs/guide.md)。原版的中文说明见上游仓库。
